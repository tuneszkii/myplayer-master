# MyPlayer Architect

Create a NBA 2k26 MyPlayer builder. Users should select a save, choose position, choose height with minimums and maximums depending on what position is selected, weight with minimums and maximums depending on what height is selected, wingspan with minimums and maximums depending on what height is selected, and handedness, Be presented Maximums and Minimums for various stats depending on what they select like three point, two point, driving dunk, standing dunk, driving lay, ect.
